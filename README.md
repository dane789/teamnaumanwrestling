# Team Nauman Wrestling Club website preview

Owner-review draft: https://dane789.github.io/teamnaumanwrestling/

This is a proposed replacement for the Middletown club website. It is a draft for review, with registration services disabled and search-engine indexing discouraged.

## Included

- Practice schedule filters, programs, coach directory, event listings, tournament-team request paths, testimonial support, directions, and club email contact.
- Public Google Calendar and Forms connection settings, ready for the club's approved accounts and links.
- Responsive layout and accessible navigation.

## Before launch

Confirm schedules, active staff, prices, membership requirements, waivers, future events, approved media/testimonials, and domain ownership. Install and test the private Google registration/roster workflow from the separately prepared setup package. Do not put family records, private Google links, credentials, or card details in this repository.

Most editable public content is in site-config.js. Keep launchReady false until club approval and live-service verification. This repository publishes its static root from main through GitHub Pages; the fuller build/Google setup package is available from the preparing administrator for the next phase.

The proposed tnwc.club domain has not been purchased or connected. This preview does not replace teamnauman.com yet.
