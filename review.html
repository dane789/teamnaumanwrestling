How to add or update a hosted event

Use TNWC - Events. Choose the Mini Camps, Clinics or Hosted Duals tab. It updates the website automatically; you do not need to edit GitHub or run Apps Script. During testing, Dane owns the Sheet. Club ownership can move later.

Open Hosted Events Sheet ↗Check events on the website →
  1. Start in an empty prepared row. Use an empty row between 7 and 103 on the appropriate tab. Leave Status as Draft while entering details. Edit an existing event in its current row instead of duplicating it.
  2. Fill columns B–J. Enter the event name, date, start and end times, full venue address, price, capacity, description and existing Google signup Form link. Mini Camps require price and capacity; Clinics and Hosted Duals allow them to stay blank when not yet known. Example: date 2026-10-25, start 09:00, end 11:45, price 25, capacity 30. All times are Eastern; use 24-hour time, such as 13:00 for 1 PM. Describe the skills being taught and what wrestlers can expect.
  3. For a multi-day event, fill End date in M with the last event day. If times vary by division, check All day in N, leave Start/End blank, and describe each division’s schedule in Details. Super Six is an example: October 10 through October 11. The site adds the correct two-day calendar entry. An optional Team signup link in O is for team organizers, separate from individual club signup.
  4. Check column L: Ready check. Correct any warning before publishing. A blank signup link allows an announcement, but the site will show that the signup link is pending. Create the Google Form separately and paste its complete link when available.
  5. Choose Published in column K. Google saves automatically. Allow a few minutes for the published feed to update, then open the website link above and refresh. Confirm the name, date, time, location, price and signup link.

Change, hide or cancel an event

  • Update: edit the existing row instead of creating a duplicate. Check Ready and verify the website after saving.
  • Draft: hides the event from the website while you prepare it.
  • Cancelled: keeps a cancellation notice visible and closes website signup. Keep the row so families can see the notice.

If an event does not appear

Check that Status is Published, Ready has no warning, and the event has not ended. Allow a few minutes and refresh the website. Invalid or duplicate rows are left off the site. If the website reports that the schedule is unavailable, ask Dane to check the feed; do not change the headings or publishing settings.

Keep the Sheet safe

Start with the Start Here worksheet. Automatic IDs are hidden; event names stay visible while you scroll. Use Check & publish → above the table to jump to Status and Ready check. Edit the prepared input cells only. Leave headings, column A (automatic ID) and column L (Ready check) alone; these areas are protected from ordinary editor changes; the owner can still edit them. Ask for more prepared rows when the Sheet fills up. Public event information only: the feed includes Draft rows too. Never enter family contacts, rosters, payment records or private notes.

This procedure publishes event details only. Signup tracking, payments and emails stay in the separate club workflow. All hosted event tabs and Travel Tournaments update the website automatically. Travel tournaments use their own worksheet in the same workbook. Public Calendar publishing is not connected.

Update prices, youth programs and announcements

Open TNWC - Club Website & Practices. These tabs update the website without a new deployment. Use prepared rows 2–40 and keep headings and Ready checks intact.

  • Prices: Amount is the total plan price; Months controls the monthly comparison. Longer-plan savings recalculate automatically against the individual monthly rate. Optional Starts and Ends use YYYY-MM-DD. Choose Published when Ready says Ready; Draft or Hidden keeps the plan off the website. Avoid overlapping dates for the same category, plan and wrestler count.
  • Programs: Keep one row each for Roots and Saplings. Edit ages, capacity, session details, coaches and the signup link. Full or Closed removes the registration link; Hidden removes the card. Ask about availability is the initial status because current open places are not confirmed.
  • Announcements: Enter a short title/message and an Expires date. Optional Starts schedules it. Choose Published after Ready; notices remain through the expiry date in Eastern Time, then disappear automatically. The supplied example stays Draft.

Save, allow a few minutes for Google publication, then refresh the site. An invalid published row hides that section’s changing information rather than showing potentially outdated prices or enrollment. All workbook tabs, including Draft and Hidden rows, are publicly published. Keep family records and payment transactions in the private workbook.
